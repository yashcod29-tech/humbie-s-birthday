HUMBIE BIRTHDAY WEBSITE — 16 PAGES

1. Extract this ZIP into a new folder.
2. Open the folder in VS Code.
3. Keep index.html, style.css, script.js, assets and music.mp3 together.
4. Put your karaoke instrumental MP3 in this main folder and rename it exactly music.mp3.
5. Open index.html in your browser (or use Live Server).
6. Click Open Your Surprise. The browser allows music after this click.
Music continues between pages. Use the top-right Music button to pause or resume.
Use Previous / Next or keyboard arrow keys. MORE HEARTS on the finale triggers an intense, full-screen shower of hearts and petals. Floating hearts are slightly more frequent on every page.
If the portrait is missing, place the image in assets/ and name it humbie.jpg.

Full-text update: the Official Humbie Description, Things I Like About You, and song memories now preserve the supplied wording and emojis. Content pages scroll so longer text is not clipped.
